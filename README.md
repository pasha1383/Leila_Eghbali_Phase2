# پیش‌بینی شاخص بورس ایران با یادگیری ماشین
## Iran Stock Market Prediction using Machine Learning

---

### درباره پروژه

این پروژه به پیش‌بینی شاخص بورس اوراق بهادار تهران با استفاده از متغیرهای کلان اقتصادی می‌پردازد.  
داده‌ها شامل **۹۲ مشاهده فصلی** از سال ۱۳۷۹ تا ۱۴۰۱ است.

**متغیر هدف:** شاخص قیمت بورس (`stock price`)  
**متغیرهای ورودی:** قیمت نفت، طلا، صادرات، واردات، نرخ ارز، نقدینگی، تورم (CPI)، چرخه اقتصادی

---

### ساختار پروژه

```
iran-stock-prediction/
│
├── data/
│   ├── raw/                    ← داده اولیه (data.xlsx)
│   └── processed/              ← داده‌های پردازش‌شده (خروجی notebook 00)
│
├── notebooks/
│   ├── 00_data_preparation.ipynb   ← ادغام، پاکسازی، EDA، ذخیره داده
│   ├── 01_xgboost.ipynb            ← مدل XGBoost + SHAP
│   ├── 02_sarimax.ipynb            ← مدل SARIMAX (اقتصادسنجی)
│   ├── 03_gru.ipynb                ← مدل GRU (شبکه عصبی بازگشتی)
│   └── 04_hybrid_pca_rf_gru.ipynb  ← مدل هیبرید ۳ لایه: PCA → RF → GRU
│
├── models/                     ← مدل‌های ذخیره‌شده (.pkl, .pt)
├── results/
│   ├── figures/                ← نمودارهای خروجی
│   └── metrics/                ← جداول معیارهای ارزیابی (CSV)
│
├── src/
│   └── utils.py                ← توابع کمکی مشترک بین همه مدل‌ها
│
├── requirements.txt
└── README.md
```

---

### مراحل اجرا

**مرحله ۱:** ابتدا `00_data_preparation.ipynb` را اجرا کنید تا داده پردازش شده ساخته شود.  
**مرحله ۲:** هر notebook مدل را به ترتیب اجرا کنید (۰۱ تا ۰۴).  
هر notebook مستقل است و داده پردازش‌شده را از `data/processed/` می‌خواند.

### روش‌های پیاده‌سازی‌شده

| فاز | مدل | هدف |
|-----|-----|-----|
| فاز ۱ | LSTM | مدل‌سازی دینامیک زمانی |

### نکات فنی مهم

- **تبدیل لگاریتمی:** شاخص بورس از ~۲,۴۲۴ به ~۱,۹۶۰,۴۵۷ رسیده (رشد ۸۰۰ برابری). تمام مدل‌ها روی `log(stock_price)` یا `log_return` آموزش می‌بینند.
- **تقسیم زمانی:** آموزش: ۱۳۷۹–۱۳۹۷ | آزمون: ۱۳۹۸–۱۴۰۱ (بدون shuffle)
- **چرخه اقتصادی:** متغیر `cycle` (مقادیر ۱، ۲، ۳) رژیم‌های اقتصادی را نشان می‌دهد.
